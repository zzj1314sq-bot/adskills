# 2026-11-25 射频链路原图增量实施记录

本记录为用户授权上传的实施摘要。原始设计、手册、运行日志与完整证据仍保留在本地受控主记录中；以下“verified”只描述本次限定结果。

## 设计决定

- 发射链路保留 PE403B 均衡器，不采用计算表中写作 YAT65 的数控衰减器；损耗须按实际 S21 曲线核算。
- 中频滤波器使用 BMBP1P65R2P35-9LG，手册插损上限 4.5 dB，2.5 dB 为带内波动，二者不能混用。
- SIS216Z 原理图实际已为 RF1 发射、RF2 接收，保持原来正确接线，更正 Visio 旧标签。
- WND0617H 天线侧接9脚、级间接5脚。

## 原理图变化

### 发射页

输入 → R19/R22/R23 固定衰减 → STCA0603N9 温补 → SIA283 → C21 隔直 → PE403B → C23 隔直 → BP。

移除 HGC301、C24 和第二组衰减；将第二组衰减 R18/R20/R21 转到 BP。保留偏置、配套去耦及范围外图元。L3 的原理图当前模型由旧 M45 纠正为原 PCB 实际使用的0603，保持原封装。

### BP 页

发射方向：SIS216Z → C215隔直 → 中频滤波器 → HGC536B → 射频滤波器 → M7101 → 3 dB衰减 → WND0617H → 天线接口。

U3 更换 HGC536B、U5 更换中频滤波器、增加 M7101 U13、相应衰减/去耦及公共端隔直。保留原工程和原页面，未发布整页重绘候选。

### 新增电容的目的

| 位号 | 值 | 作用及依据 |
|---|---|---|
| C209/C210 | 100 pF / 1000 pF | M7101 的 −5 V VEE去耦；配合复用的 C20/C19，为两个 VEE供电点配置两组去耦 |
| C211/C212 | 100 pF / 1000 pF | M7101 接收支路 VR 的 +5 V供电去耦 |
| C213/C214 | 100 pF / 1000 pF | M7101 发射支路 VT 的 +5 V供电去耦 |
| C215 | 100 pF | 串接 U5 与 SIS216Z RFC公共端，阻断端口直流偏置沿中频路径传递 |

M7101 手册第7页给出供电压点，第8页装配图给出四组100 pF＋1000 pF配置；SIS216Z 手册明确各 RF端口有电压、公共端内部无隔直，需要外接隔直电容。C19/C20 是复用件，不计入新增七只。最终就近布局、接地回路及实际射频性能尚未验收。
