# 封装设计、原理图修改与 PCB 增量同步

这份文档记录两部分设计流程，以及 2026-11-25 一次射频链路更新的实际结果。它是本地主记录的发布快照，后续更新需重新核对证据，不把历史成功直接当作当前环境的能力。

| 部分 | 职责 | 输出 |
|---|---|---|
| 第一部分：Visio 整体链路设计 | 收发、本振、电源、控制、接口及必要预算 | 已确认框图、参数基线、器件与连接变更清单 |
| 第二部分：AD26 设计落地 | 符号/封装、真实模型绑定、库编译、原图增量修改、限定转 PCB 和验证 | 配套库、原理图、PCB、证据与待办 |

**后续第二部分统一使用 AD26。** 本次封装生成、绑定、编译实际仍在 AD22 完成，随后由 AD26 完成原理图和 PCB；完整封装自动化尚待在 AD26 移植验收。[要求与实际状态 →](docs/platform-policy.md)

## 验收范围

- 封装库数据、原理图连接、PCB 同步、布线完成、指标达标、制造放行分别验收。
- `attempted` / `partial` / `failed` / `verified` 必须对应具体输入、版本和证据范围。
- 本次验证包括原图增量、模型与编译产物回读、限定 PCB 更新、板外排布、连接刷新、保存重开以及源/PCB 无差异预检。
- 本次未完成全工程 ERC/DRC、完整射频性能验收和制造放行。裸芯片载体与键合设计仍为装配草案。

本目录是设计流程与实施记录，不包含真实原理图/PCB/器件库文件、原始厂家手册、机器配置或可直接执行的设计脚本。克隆仓库不会操作 AD。
