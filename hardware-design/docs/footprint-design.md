# 器件符号与封装设计流程

目标：从有来源的器件参数生成可绑定、可保存、可编译、可独立回读的库对象。后续执行平台为 AD26；本次固定裸芯片生成流程的历史验证宿主为 AD22，移植状态见[平台要求](platform-policy.md)。

## 1. 一次建立参数基线

先确认原有库中是否已有合格模型。需要新增或修正时记录：

- 完整型号、厂家、手册版本/页码及输入文件指纹。
- 本体长宽高、公差、视图、坐标原点及单位；底视图必须显式换算。
- 原理图引脚编号、名称、电气类型、供电/控制条件和真实功能。
- 封装焊盘或裸芯片键合点位置、尺寸、金属化与背面电气属性。
- 型号、模型名、批准库来源，以及厂家数据、用户规则、估算值的区别。

缺项集中处理，不自行决定器件型号、引脚网络、封装或位号。只对变化部分复验，不覆盖已经正确的符号身份、模型或用户并行修改。

## 2. 区分封装料与裸芯片

封装料依据厂家推荐焊盘及实际工艺设计。裸芯片还需表达芯片贴装区、原始键合点、外围线焊落点及三者间的电气映射。

下表是本项目同类裸芯片载体的约定，不能当作所有器件或板厂的通用制造标准：

| 内容 | 同类项目约定 | 必须核对 |
|---|---|---|
| 中心贴装铜 | 本体每边外扩 0.10 mm，Top Layer | 背面属性及实际导电贴装方式；不能默认接地 |
| 原始键合点参考 | 按厂家位置表达在 Mechanical6 | 它是参考标识，不是顶层铜焊盘 |
| 隔离标识 | 中心铜外缘再每边外扩 0.10 mm，Mechanical13 | 标识不自动形成电气 Keepout |
| 外围线焊落点 | 0.30 × 0.30 mm，同侧密集落点参考中心距 0.40 mm | 实际铜间隙、转角、编号次序和键合可行性 |
| 阻焊 | 铜外缘每边 +0.01 mm 的草案规则 | 实际开窗、阻焊桥与工厂能力 |
| 锡膏/贴装 | 外围线焊焊盘默认无锡膏开口；中心按贴装工艺单列 | 铜面积不等于点胶或锡膏面积 |
| 字符 | TrueType、Arial；编号和功能名分开 | 保存后的字体、位置、字形边界、重叠与可读性 |
| 三维体 | 按有来源的本体长宽高建立 | 不用无依据的旧 Height 或默认方块代替手册 |

保留“原始键合点—外围焊盘—原理图引脚”对应表。同号地焊盘可以有多个，物理焊盘数与唯一编号数分别统计；不能用字典去重掩盖重复焊盘。

## 3. 固定落地顺序

参数基线 → 符号/封装离线几何检查 → 目标库受控写入 → 独立回读和保存 → 真实 PCBLIB implementation 绑定 → 原生编译 → 最终产物验收。

执行时复用批准的库与入口。不能把某型号的一次性程序当作通用入口，也不在新任务里复制整库或另建一套生成流程。

## 4. 验收对象

| 层次 | 检查内容 |
|---|---|
| 符号 | 型号/设计项身份、引脚数量/编号/名称、电气类型、旧引脚和旧图元是否残留 |
| 封装 | 焊盘编号多重集、尺寸、位置、旋转、图层、阻焊/锡膏、相关机械边界与三维体 |
| 模型绑定 | 准确库来源、唯一 current 模型、实际模型名、引脚—焊盘对应 |
| 持久化 | 精确保存目标库后，独立读取保存文件；不以未保存内存或“命令成功”代替 |
| 编译产物 | 核对最终符号与封装 payload、交叉引用 xref，而非只检查封装名字串存在 |

只填写名为 Footprint 的文字参数不构成模型绑定。字符或引脚映射修改完成后，应以最终源和最终编译产物验收。
