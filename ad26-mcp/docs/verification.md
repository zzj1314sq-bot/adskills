# 验证范围与不应扩大解释的结论

这些是2026-11-25整理的历史验收范围，不是本仓库在读者机器上运行AD所得的结果。GitHub离线校验也不能将它们升级为本机native验收。

| 范围 | 已有证据支持 | 不支持的扩大结论 |
|---|---|---|
| 原理图基础查询 | 已加载原理图的元件/UID和_doc | 任意未加载文档、库元件迭代或所有入站Unicode |
| 原理图限定编辑 | 批量修改、线/网标/端口等指定用例与读回 | 任意设计安全、真库放件或保存重开已全部验收 |
| 库侧七命令 | 符号/参数/模型链接/封装/pad读取、选中、卸载的dry_run及缺确认拒绝 | 真实卸载、alias_name、全部选项大批量运行 |
| PCB五命令 | 统计、元件、叠层、机械层、显示隐藏再还原 | 全PCB编辑、规则/铺铜/自动布线或制造放行 |
| 几何v6 | 修正后的12项验收、完整counts/数组/limit/guard/拒绝、符号入口小样本形状 | 纯图形kind、完整折线顶点、符号名称/文件名或所有层级关联 |
| 运行时 | 同宿主手动停启及外部守护一次恢复闭环，历史测量约13s | 无限重试、所有崩溃场景、自启动/永久无人值守 |
| 创建探针 | TEMP PcbLib内创建/注册、三个pad读回、移除并保持未保存 | 创建命令已进入47清单、完整封装图元、保存重开发布 |

此前工程查询虽有功能请求通过，部分性能条件未达，不据此声称所有工程性能已优化。业务工程的同步任务必须单独验收；MCP恢复不等于原理图到PCB的业务更新完成。

规范的keys_ok、values_ok、verdict要分别记录。有效阴性不自动失败，空数组不自动成功；缺必需键不允许给默认值后判通过。验收规格修正可以对保存的原始响应复判，但要保留原判据和原因，不改写成实现变更。

本仓库不上传真实设计、库、完整运行日志或内部监督文件。合成示例与历史摘要仅支持理解协议；正式native验收由使用者在获准副本上取证。
