文档包版本 **1.0.0**，整理日期 **2026-11-25**。基于一个 AD26 `ad26-unified-v1.3-generic` 实装基线，原生协议版本 `26`，登记 **47 条原生命令**。

这是可复用的协议说明、流程和被动任务模板。**没有打包可直接运行的 Altium 原生脚本、安装器或本机配置**；克隆本仓库不会自动连接、启动或修改 AD。

## 最容易混淆的三件事

1. 47条原生命令不等于47个stdio MCP工具。所检查适配器的标准tools/list只有5个工具；新增原生命令不会自动成为独立MCP工具。
2. `protocol_version:26`是本项目原生IPC版本，不是MCP标准版本号或AD所有版本的通用协议。
3. `verified`只适用于具体源码、参数、前提和证据范围。探针能创建封装，不等于正式创建命令或保存重开已交付。

所有示例均为合成数据，路径仅为`C:\AD26_TEST`占位。未上传真实工程、器件库、原始运行日志、账号凭据或本机profile。上游原生实现需单独取得并审查许可；此包未代为重分发它们。

## 使用方式

先读协议与准备，复制被动任务模板并填写授权、基线、测试副本和判据。使用现有受控适配器执行任务；本包校验脚本只读文件，不调用AD、不执行MCP、不启动进程。不要把模板中的示例身份或路径用于生产。
